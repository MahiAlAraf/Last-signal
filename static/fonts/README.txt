PUT THE POLARIS SPACE FONT HERE
================================

1. Download "Polaris Space Font" from the page you found on designshack.net.
   Read its licence on the download page (is it free for your use?).

2. Copy the font file into THIS folder and rename it to exactly one of:
       Polaris.woff2      Polaris.otf      Polaris.ttf

3. Reload the website with Ctrl+F5.

style.css already points to these three names (see "1. FONT AND COLOURS").
Until the file is here, the website uses the Segoe UI font, so nothing breaks.
